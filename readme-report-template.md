# readme-report-template

## Overview
This file demonstrates Markdown formatting. You can write normal text by not placing a hashtag symbol (#) at the start of the line. For a line break, put two spaces at the end of the line and then add an enter, as follows:  

This text comes after the line break.  

You can add emphasis to text by using asterisks. *This is in italics.* **This is in bold.**  

You can add links using the following format: [course GitHub](https://github.com/dmhuehol/ev228-analysis-of-environmental-data).
The text that is inside the square brackets will be the text that is displayed.

### Adding a figure
To add a figure, include the figure in your repository and push it to Github. Then, open the image from your repository on GitHub on the web. Copy the link and link to it similar to a normal link *except* add an exclamation point ! before the bracket.
