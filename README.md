# ev228-analysis-of-environmental-data
Code for EV228: Analysis of Environmental Data at Colorado College.

## Code Index
Code is in the root directory. Unless otherwise specified, all code is in Python.
* `count_outcomes`: Count and display outcomes for a virtual dice roller
* `eda_distributions`: Exploratory data analysis for statistical distributions
* `eda_general_demo`: Demonstration of general exploratory data analysis workflow
* `fun_eda_demo`: Module of functions to support exploratory data analysis
* `fun_grid`: Module of functions to support gridded data
* `fun_probability`: Module of functions relating to probability tasks
* `load_netcdf`: Load and explore netCDF gridded data
* `probability_distributions`: Demonstrate generating and visualizing probability distribution functions
* readme-report-template: *Written in Markdown*, depicts example formatting for the Individual Data Analysis Readme and other Markdown assignments
* `station_load_csv`: Load and explore timeseries data from weather stations
* `tic_toc`: Demonstrate tic-toc profiling
* `trials_needed_for_value`: Assess relationship between expected value and number of trials for a dice roller using a Monte Carlo approach
* `utensils_fun_demo`: utensils demonstration written in functions
* `utensils_script_demo`: utensils demonstration written as a script
* `vectorized_example`: Demonstrate runtime difference between loop and vectorized operations

## Reading Index
